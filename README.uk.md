# Mini Web Scanner

Python 3.11+ проєкт модульного сканера безпеки вебзастосунків. Версія 3.0.0 перебуває в розробці. Наразі код містить базові моделі сканування та знахідок, а також конфігурацію сканера з перевіркою параметрів. Рушій сканування та інтерфейс користувача ще не реалізовані.

## Поточний стан

У `src/webscanner/` реалізовано:

- Моделі `Scan` і `ScanStatus` для стану сканування, часових міток і списку знахідок.
- `Finding` і `Severity` для опису знахідки та її рівня критичності.
- `ScannerConfig` для налаштувань сканера з перевіркою тайм-ауту, перенаправлень, затримки та ліміту запитів.

Скрипт `scanner.py` належить до попередньої версії та не є частиною пакета версії 3.0.0.

## Вимоги

- Python 3.11 або новіший

## Встановлення для розробки

```bash
python -m venv .venv
# Активуйте віртуальне середовище, потім виконайте:
python -m pip install -e ".[dev]"
```

## Тести

```bash
python -m pytest
```

Наявні тести перевіряють моделі та валідацію конфігурації. Вони поки не охоплюють HTTP-сканування, створення звітів або CLI.

## Структура проєкту

```text
src/webscanner/
  core/config.py
  models/finding.py
  models/scan.py
tests/
  test_models.py
```
